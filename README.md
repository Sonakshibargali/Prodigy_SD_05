# 🛒 E-Commerce Web Scraper

> **Prodigy InfoTech — Software Development Internship | Task 05**

A Python-based web scraper that extracts product information from an e-commerce website and stores the collected data in a structured CSV file.

## 🚀 Features

- Extracts product name, price, rating, and availability
- Scrapes multiple pages automatically
- Handles pagination
- Removes duplicate products
- Cleans and validates extracted data
- Includes retry and error handling
- Adds scraping timestamps
- Generates summary statistics
- Exports data to CSV
- Maintains logs of scraping activity

## 🌐 Website

**Books to Scrape** — https://books.toscrape.com/

The website is designed as a practice environment for web scraping and contains book information such as names, prices, ratings, and availability. :contentReference[oaicite:2]{index=2}

## 🛠️ Tech Stack

- **Language:** Python
- **HTTP Requests:** Requests
- **HTML Parsing:** BeautifulSoup4
- **Data Storage:** CSV
- **Logging:** Python Logging
- **Data Processing:** Regular Expressions

## ⚙️ Setup & Run

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the scraper

```bash
python scraper.py
```

The scraper visits the available pages, extracts book information, and saves the results inside the `output/` folder. :contentReference[oaicite:3]{index=3}

## 📊 Extracted Data

The generated CSV contains:

| Field | Description |
|---|---|
| Serial Number | Product number |
| Product Name | Name of the book |
| Price | Price in GBP |
| Rating | Rating from 1–5 |
| Availability | Stock availability |
| Scraped At | Date and time of scraping |

## 🧠 Scraping Process

```text
Website
   ↓
Send HTTP Request
   ↓
Parse HTML with BeautifulSoup
   ↓
Extract Product Information
   ↓
Clean & Validate Data
   ↓
Remove Duplicates
   ↓
Save to CSV
```

The scraper processes pages, extracts product information, checks for duplicates, and saves the collected data as a timestamped CSV file. :contentReference[oaicite:4]{index=4}
